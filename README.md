## Descripción

Esta aplicación permite:

- Agregar tareas al inicio o al final de la lista
- Insertar tareas en una posición específica
- Marcar tareas como completadas o reabrirlas
- Eliminar tareas seleccionadas
- Visualizar la estructura interna de la lista enlazada en un diagrama
- Ver el estado general de las tareas pendientes y completadas

## Estructura del proyecto

- `main.py`: punto de entrada de la aplicación
- `app.py`: lógica principal de la interfaz gráfica
- `linked_list.py`: implementación de la lista enlazada
- `node.py`: definición del nodo de la lista
- `interface.py`: componente gráfico para dibujar la estructura

## Requisitos

- Python 3.8 o superior
- Tkinter

## Cómo ejecutar

Desde la carpeta del proyecto, ejecuta:

```bash
python main.py
```

## Uso

1. Escribe una tarea en el campo "Task".
2. Elige si la quieres añadir al inicio, al final o en una posición específica.
3. Selecciona una tarea de la lista para completarla, reabrirla o eliminarla.
4. Observa la representación visual de la lista enlazada en la parte inferior.
